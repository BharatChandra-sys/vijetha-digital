## Step-by-Step: How to Request Indexing in GSC

### Step 1: Access Google Search Console
1. Go to https://search.google.com/search-console
2. Log in with your Google account
3. Select your property: `vijethadigital.com`

### Step 2: Submit Sitemap (One-Time Setup)
1. Click **Sitemaps** in left sidebar
2. Enter: `sitemap.xml`
3. Click **Submit**
4. Verify it shows "Success" status

This tells Google about all your pages automatically.

### Step 3: Request Indexing for Individual URLs

**For each priority URL:**

1. Click **URL Inspection** at the top of GSC
2. Paste the full URL (e.g., `https://vijethadigital.com/about`)
3. Press Enter and wait for Google to check

**If URL is NOT in Google:**
- You'll see "URL is not on Google"
- Click **REQUEST INDEXING** button
- Wait 1-2 minutes for validation
- Google will crawl within 1-7 days

**If URL is already indexed:**
- You'll see "URL is on Google"
- Click **REQUEST INDEXING** anyway to refresh
- This updates Google with your latest content

### Step 4: Monitor Coverage

1. Go to **Pages** section in left sidebar
2. Check "Why pages aren't indexed" section
3. Fix any issues reported:
   - "Crawled - currently not indexed" → Request indexing manually
   - "Discovered - currently not indexed" → Request indexing manually
   - "Server error (5xx)" → Check hosting
   - "Not found (404)" → Fix broken links

## Common Issues and Solutions

### Issue: "Discovered - currently not indexed"
**Solution:** 
- Request indexing manually
- Add more internal links to the page
- Ensure page has 300+ words of content

### Issue: "Crawled - currently not indexed"
**Solution:**
- Google saw it but deemed it low priority
- Improve content quality and uniqueness
- Add more backlinks to the page

### Issue: "Excluded by 'noindex' tag"
**Solution:**
- Check robots meta tag
- Remove noindex if present
- Re-request indexing

### Issue: "Soft 404"
**Solution:**
- Page has too little content
- Add more text, images, and value
- Ensure proper heading structure
